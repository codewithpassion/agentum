## Verdict

Clean: 0 must-fix, 3 nits.

The round 1 must-fix (V2-1 finding 1) is resolved. `tasks.get` now reads `TASK_EVENT_TYPES`, which is `STREAM_EVENT_TYPES` plus `connector.call`, `connector.needs_auth` and `connector.timeout` (`apps/web/src/server/session-stream-frames.ts:40`, `apps/web/src/server/compose.ts:586`). `STREAM_EVENT_TYPES` is unchanged, so the live gate and the replay filter still carry no connector events. The proxy records connector events with the run's `runId` and `sessionId` (`apps/web/src/server/routes/proxy.ts:328`), so `runEvents` keeps them and `toActionLog` turns failures into `error` entries on load and reload. Live, they still appear only after a reload, which is what V2.11's refinement expects.
