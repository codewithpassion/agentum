# CL.5 review: shared helpers in apps/web

Branch task/CL.5-web-shared-helpers. Implementation commit 47896377.

## Verdicts

Round 1 (Opus, 47896377): clean, no must-fix. 0 fix rounds.

## What changed

- `server/routes/respond.ts`: `jsonError`, `serviceRefusal`, `bearerChallenge`, `bearerUnauthorized`, `tokenUnauthorized` and `sessionUser(c, deps)`. Status codes and bodies are unchanged.
- `integrations/trpc/load-or-login.ts`: `loadOrLogin(fn, notFoundOn?)` and `hasTrpcCode`.
- `lib/error-message.ts`: one `errorMessage(error, fallback?)` and `errorReason(error)`.
- `ServiceError` takes an optional `reason`. The tRPC error formatter sends it as `data.reason` (always present, null when none). The assistant uses `ERROR_REASON.keyInMessage` and no longer matches "That looks like a key".
- `startPolling` in `components/inbox/use-polled-query.ts` is the shared poll core. `usePolledQuery` uses it, and so do the guest, live artifact and deck panels, the task mail and files slots, the artifacts slot, the library refresh and the session-events fallback. All of them skip ticks in a hidden tab and run again on focus.
- `settings.artifacts.tsx` reads `artifacts.linksEnabled` directly.
- Removed the redirect routes `/connectors`, `/machines` and `/settings/managed-agents`. `routeTree.gen.ts` regenerated by the build.
- `docs/v3/workspace-assistant.md` now describes the panel.

## Counts of removed copies

- Local `errorMessage` definitions: 40 removed (34 with the "Something went wrong." fallback, 5 with `String(error)`, 1 with "The request failed").
- Inline `x instanceof Error ? x.message : "..."` expressions: 95 replaced with `errorMessage(x, "...")`.
- Loader `UNAUTHORIZED` redirect blocks: 27 replaced by `loadOrLogin`.
- Server `refusal`, `jsonError` and `unauthorized` copies: 13 removed from routes (skills, run-library, files, triggers, machine-runs, desk, session-stream, egress, proxy, mcp and others) in favour of `respond.ts`.
- Session lookups: `sessionUser` replaces the copy in files, library, desktop, connectors-oauth and session-stream.
- `setInterval` network polls: 11 moved to `startPolling`.

Tests: web 4366 before, 4383 after (17 new: respond, load-or-login, error-message, the reason over HTTP). Services and the rest unchanged and green. Bundle grep for `drizzle` in `apps/web/dist/client` is clean.

## Nits left

- `sessionUser` passes no `orgRole`, as before, so cookie routes see `isAdmin: false`. `routes/artifacts.ts` keeps its own copy because it needs `orgRole`.
- `connectors-oauth.ts` and `desktop.ts` call `deps.session(c)` twice (guard, then `sessionUser`).
- The "What a service refused with" comment in desk, triggers and machine-runs now sits over a wrapper that adds only the ZodError case.
- A thrown non-Error used to show `String(cause)` in about 20 places and now shows "Something went wrong.". `a.$artifactId.tsx` gains a trailing period.
- A few one-line `messageOf` wrappers remain (task-page, thread-title, composer-container, task-thread, agents.new).
- `errorReason` returns `string | null`, not `ErrorReason`.
- `components/artifacts/grant-approval-model.ts` and `guests/viewer.tsx` still match server wording.
