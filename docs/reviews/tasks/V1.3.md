## Nits left

- Approval cancelled text ("The call was withdrawn because the run is ending.") is not in the task text. It mirrors the question wording.
- An answered question with an empty answers map returns an empty string.
- A whitespace-only deny note adds trailing spaces.
- Backticks inside a command are not escaped in the "Run `...`" summary.
- The 200 character cap slices UTF-16 units and can split a surrogate pair.
- The Claude Code prefix does not sanitise the server key as the Pi branch does. Current slugs make this harmless.
- Long comment on `askUserQuestionAnswers`.

- `askUserQuestionAnswers` filters the answers to the questions asked. It does not join multi-select answers, because `questionAnswerSchema` already holds strings. The surface that collects answers (V1.13, V1.14) joins them with ", ".
- A Pi tool name cut or sanitised by `piToolName` cannot be mapped back to the original tool name. V1.10 should pass `server` and the original tool name to `toolKey`.
