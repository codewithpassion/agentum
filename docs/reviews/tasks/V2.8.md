## Nits left

- `deskInputSchema.dayStart` uses `z.iso.datetime()` without offsets, so a `+11:00` time is refused. A browser `toISOString()` value always passes.
- `pendingRequests` relies on `requests.listPending` to authorize, as the old `needsYou` did.
- Needs you only sees the threads `inbox.listThreads` returns (50). An agent-answered thread past that is left out.
- `latest.find` per thread and `pending.filter` per run card are quadratic in memory. Maps would match the rest of the file.
- A skill proposal by a person on an ownerless skill has `agentId: ""`.
- The events band read has no `workspaceId` condition. The run ids come from workspace-scoped rows.
- Running is ordered by `createdAt`, while a card's `at` is `startedAt ?? createdAt`.
- `needsYouSources` finishes before the run queries start, and the name lookups repeat per lane.

## Beyond the scope

- A read marker for inbox threads, so a thread an agent answered leaves Needs you once a person has read it, not only when one replies.
- A wider `IN` batch helper shared with `library.ts` and `skills-store.ts`, which each have their own `chunks`.
