# V7.3 review: Map view, Runs mode with inspector

## Verdicts

Round 1, commit 8809332: not clean, two must-fix.
- An upward handoff edge used the handles "top" and "bottom", which pair a source with a source and a target with a target, so xyflow drew nothing. Fixed with a source handle "top-out" and a target handle "bottom-in" on the agent node.
- The inline approval and "Open task" followed the agent's newest run, not the waiting one. Fixed with `shownRunOf` in `inspector-logic.ts`, which finds the run by `pendingRequest.runId`.

Round 2, commit 2b6e113 (fix commit only): clean.

Nits fixed along the way: React keys on the Starts and Fed by chips, `agentIdOf` reused in the inspector, arrow markers on wires, and the approval showing when the profile fails to load.

## Nits left

- `handlesOf` doc comment in `map-logic.ts` does not mention that same-height handoffs run right to left.
- The inspector heading says "Last run" when it shows the waiting run.
- The status band tone union is written twice in `inspector-logic.ts`.
- Trigger pills show no second line (`detail` is empty). The cron text or mail address would fit there.
- Wire colours are hex values and the green and yellow states use Tailwind emerald and amber, not app tokens, so they read the same in light and dark.
- Two agents handing to each other draw two edges along one vertical line.
- The theme starts as light and switches in an effect, so a dark page can flash light tokens in the map on first paint.
- Four wide port chips can wrap past the 76px tile height.

## Beyond the scope

- The Q&A node shows its 7-day question count, not an open count. No service exposes open Q&A items before V7.8. V7.8 should add the open count to the node and the link to `/qa`.
- Agent run counts come from `tasks.list` with limit 100, counted over 7 days. A busy workspace saturates the list. A per-agent run count in `MapGraph` (V7.2 service) would be exact.
- Trigger "recent items" are the last fired time and the 7-day wire count. A list of recent runs per trigger needs a service read.
- Editor mode is a disabled button. Dragging, wiring and `map_positions` writes come with a later task.
- Handoffs between agents in one column make the default layout stack the agents. A layered layout in `MapGraph` positions would read better.

## Steps for Dom

None. The browser check ran locally with seeded rows: nodes and counts, a yellow waiting node, the inspector with an inline Allow once that cleared the waiting state, Fit view, and dark mode.
