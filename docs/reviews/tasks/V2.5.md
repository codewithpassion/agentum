# V2.5 implementation review

Non-empty Claude Code thinking blocks now produce `message.reasoning` events
with their text preserved. The existing block traversal keeps reasoning, text
and tool calls in message order. Empty thinking and redacted thinking emit no
events. No protocol or server changes are needed: V2.1 already widened
`runEventInputSchema`, which supplies `NormalizedEvent.type`.

## Release order

Release the Worker containing V2.1 before releasing this daemon. An older
Worker's strict upload schema rejects `message.reasoning` and refuses the
whole event batch.

## Interpretation

As with existing text blocks, "empty" means exactly the empty string;
whitespace is preserved verbatim. This is documented beside the new branch.
