# V2.5 review

Non-empty Claude Code `thinking` blocks now become `message.reasoning` events in
`assistantBlockEvents` (`apps/daemon/src/normalize.ts`), in block order with the
text and tool_use events of the same message. Empty thinking and
`redacted_thinking` give no event. No protocol or server change: V2.1 already
added `message.reasoning` to `runEventInputSchema`, and `NormalizedEvent.type`
follows from it.
