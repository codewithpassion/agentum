## Nits left

- `fileTime` shows UTC HH:MM with no label, while the receipt tiles show local time. `formatMtime` in `library-logic.ts` labels UTC and would fix it.
- Open in library always renders, but the library page throws not_found for a folder that does not exist. It only bites queued runs and runs from before `runs.ts` created the folder at dispatch.
- The conflict row's original path is plain text, and Compare opens only the conflict copy, because no compare view exists yet.
- The 5 s interval does not wait for the previous request, so a slow response can land after a newer one.
- The panel polls while the run is queued, offered or waiting, not only running (it follows `isActive`).
- No test covers the polling and the final read. Only the pure helpers are tested.
- An outside edit's link can 404 when someone else deleted or moved the file after the run wrote it.

## Ideas beyond scope

- A real Compare view in the library page (V4.17 or later), linked from both the Files panel and Needs you.
- A "Download all" for the folder, as the design shows.
- Mode (read or write) next to an outside edit needs the grant from `taskFiles`. The panel shows the version op for now.
