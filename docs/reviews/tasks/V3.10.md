# V3.10 review

Task: One-page agent profile replacing the eight tabs. Branch task/V3.10-profile-page.

## Verdicts

- Round 1 (bc3cc9b): clean, 0 must-fix, 7 nits. No fix rounds.

## What changed

`/agents/$agentId` is one profile page. The loader calls `agentProfile.profile` and `agents.get`. The header shows the tile, name, address (or a "Reserve an address" chip that calls `checkAddress` and `reserveAddress`), the runtime in plain words, a status pill that links to the task the agent waits on, Edit and Run now. The `tab` search param and `agent-tabs.ts` are gone. A `sheet` search param opens a manage sheet.

`components/agent/profile/` holds the rows (Does, Voice, Tools, Skills, Hands to, Starts on, Channels, Library), `profile-logic.ts` with its test (chip text, runtime words, status text), and `manage-sheet.tsx`. Voice saves through `agents.update({ soul })`, Hands to through `handsTo`, the library list through `runtimeConfig.libraryPaths`. The old tab panels moved to `profile/sheets/` with `secrets/` and `skill-tree`. Tools opens connectors and secrets, Starts on opens triggers and a new routines panel, Channels opens Slack, Edit opens `tabs/settings.tsx` (still there for V3.11). `tabs/sessions.tsx` is deleted. The page reloads its data when a sheet closes.

The connector OAuth return links changed from `?tab=connectors` to `?sheet=tools` (service default, Hono route, tests), so a connect flow lands on the Tools sheet.

Browser check on a local dev server: every row renders, voice saves and survives a reload, an address and a library folder save, and the Tools (assign a connector, grant a secret), Skills (assign), Starts on (create trigger and routine), Hands to and Edit sheets work. The Slack sheet opens with its setup form. Creating a real Slack app needs a bot token, so that step was not run.

## Nits left

- `profile-logic.ts`: the "Draft" status and the "Slack app · revoked" chip cannot occur, because the service refuses drafts and drops revoked apps.
- `chip-list.tsx`: the `empty` prop has no caller.
- `profile-rows.tsx`: the `open()` helper sets an empty label that every caller overwrites.
- `sheets/hands-to.tsx`: the picker lists active agents only, so a hand-off to an archived agent shows as a chip but cannot be unticked.
- `library-paths.ts`: the agent's own home path is accepted and then shows twice (duplicate React key).
- `address-chip.tsx`: Reserve sends two `checkAddress` queries (blur and submit).

## Ideas beyond the scope

- The address chip shows `local@` with no domain. Add the domain when V5.3 provisions mail.
- The Xero-style connector chip turns amber when a connector needs auth, but the sheet does not say why. A short reason on the chip would help.
