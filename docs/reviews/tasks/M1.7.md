## Decisions

- `openLocalDatabase` now opens through a new `openSqlite(file)` helper that sets `PRAGMA busy_timeout = 5000` and then turns foreign keys on. It was the only place a script opened the local D1 file, so every dev and e2e script gets the wait.
- The test holds the write lock in a child process. A blocked write in the test's own process would also block anything there that could release the lock. Without the pragma the write throws "database is locked"; with it, the write waits and succeeds once the child commits.
