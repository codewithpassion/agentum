# V5.16 review

## Verdict

Round 1, commit 45d3402: clean. No must-fix findings.

## What changed

`receive` in `packages/services/src/mail/inbound.ts` now stores and indexes mail from an address of the same workspace (`storeInbound`, `mail_threads`, `mail_messages`, `mail.received`) and starts no run. This keeps the loop guard against agent ping-pong. `Auto-Submitted`, list and bulk mail are still dropped before anything is stored. Mail from an outside address still starts a run.

## Nits left

- The `own` mailbox query runs before the auto-submitted and list early return. It could move below it and skip a query for dropped mail.
- The test sets both From and envelope sender to the agent. Nothing tests a match on only one of the two.
- The agent check trusts the From header, and the mail path does no SPF, DKIM or DMARC check. An outside sender who spoofs an agent's address now has the mail stored and shown as if the agent sent it, with no run started. Before, it was dropped. The gap predates this task.
