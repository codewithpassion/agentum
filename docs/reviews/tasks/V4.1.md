## Nits left

- `packages/db/migrations/0018_rare_doctor_strange.sql`: the `libraryPaths` copy only trims slashes, as the refinements ask. A saved value such as `./docs` or `a//b` becomes a grant that never matches a normalised path. V4.19 or V4.21 can normalise on read, or clean the rows.
- `packages/db/src/schema/library.ts`: `library_versions.author_kind` is plain text, with no enum constant in `shared.ts` (`user | agent`).
- `packages/db/src/schema/library.ts`: `agent_library_access` has no index that starts with `workspace_id`. Listing a workspace's grants scans the table. Per-agent lookups use the primary key.
- `packages/db/src/foreign-keys.test.ts`: the set-null test builds its suggestion by hand instead of sharing the builder from the earlier test.
- `library_links` has `workspace_id` in its primary key (the scope listed only `from_path` and `target`). That is deliberate, since paths are unique only within a workspace.
