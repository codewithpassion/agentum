## Nits left

- A status push with `youHaveControl` clears any input error, not only the lost-control one.
- Frames are acked on arrival, before `createImageBitmap` and the draw, so slow decodes can pile past the server's two-frame limit.
- `control` in a status message is cast without a shape check (`desktop-stream.ts`).
- A socket the server refuses (401, 403, revoked machine) is retried every 4 s for as long as the page is open.
- A second mouse button pressed while another is held arrives as `pointermove`, so a right-click during a left drag is lost.
- If `youHaveControl` is true while `takeover` is null (briefly after the request settles), "Hand back" does nothing and shows no message.
- The painter, the hooks and `desktop-clipboard.ts` have no unit tests. The stream, input, coalescer, status and `pendingTakeover` logic do.
- The hidden-tab test resumes with a new frame, not a `visibilitychange`.

## Beyond scope

- Dropped from the agentum port on purpose: expand to full size, the reserved-chord buttons (Ctrl+W, Ctrl+T), the send-text box and the lease-expiry warning.
- Every task page whose agent has a computer opens a viewer socket, finished runs included, and shows the computer's current screen. The scope says to render it whenever the agent has a computer. A finished run might hide it.
- `TaskView.agent.computerMachineId` is new. `agent.machine` stays the machine the session runs on.
- The Needs you and receipt `TakeoverCard` lost its Take over and Hand back buttons. Those live in the screen panel now, since taking over without a screen has no use.
