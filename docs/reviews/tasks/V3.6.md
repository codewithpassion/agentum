## Deviations from the task file

- `tool_choice` is `{ type: "auto" }`, and the system prompt names the `draft_agent_profile` tool. The default model, `claude-sonnet-5-5`, answers a forced `tool_choice` (`tool` or `any`) with a 400 per the current Anthropic API reference. The Refinement's `tool_choice: { type: "tool", name }` is therefore not in force. A reply with no `tool_use` block counts as a bad reply and gets the one retry.
- `createAgentBuilderService` takes `agents`, `connectors`, `fetch`, `machines`, `managedKeys`, `modelKeys` and `skillsStore`. It takes no `db` or `clock`, because it reads through other services and writes nothing.
- The catalogue offers every cached tool of every connector and never calls `connectors.assignments`, because the agent doesn't exist yet. The `BuilderCatalog` comment in `draft.ts` ("Only assigned tools") is stale for that reason.
- The records carry no description, so a connector's `description` is its URL, a skill's is empty (only people-owned skills are offered), and an agent's `does` is the first 200 characters of its instructions.
- `catalog.runtimes` holds `machine` when a non-revoked machine exists, `managed` when the workspace has an Anthropic key, and `cloud` when it has an Anthropic or an OpenRouter key.
- The routine `prompt` default stays a zod transform. The tool schema is built with `z.toJSONSchema(agentDraftSchema, { io: "input" })`. The `locked` undefined-key nit from V3.5 is fixed in `reconcileDraft` and has a test.

## Nits left

- No `strict: true` on the tool. Strict mode needs every property in `required`, and `machineId`, `prompt` and `timezone` are optional.
- Every non-ok status gets the same retry and the generic message, so a revoked workspace key shows as "could not draft" and not as a key problem.
- The fetch has no timeout or abort signal, and no `output_config.effort` or refusal `fallbacks`.
- Skills without an approved version are still offered.
- The connector URL, query string included, goes to Anthropic in the prompt.
- The V3.5 nits in `draft.ts` that this task didn't touch: duplicate gaps for a duplicate unknown id, the "No agent for Ghost yet" wording, the untrimmed routine `label` and uncapped `cron`, a `machineId` kept for a `cloud` runtime, and "Runs on cloud" showing the raw runtime key.
