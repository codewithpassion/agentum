## Nits left

- The approval card's body `pre` and address rows have no wrapping or overflow rule, so a very long URL can overflow a narrow card.

## Ideas beyond the scope

- `mail.today` counts held mail only if it was created today, so a mail held yesterday and still waiting reads as 0 held. Counting every currently held message would match "held for approval" better.
- The strip's day uses the workspace timezone and the desk board's day uses the browser's local midnight. They differ when the two zones differ.
