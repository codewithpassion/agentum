- On a stale card the stale sentence replaces the agent's summary, and the diff still runs from the old base. Edit first loads the proposed text, so accepting it overwrites any newer page edits.
- `OpenTaskLink` in `conflict-resolver.tsx` repeats the one in `needs-you-card.tsx`.
- The Compare button is not disabled while it loads and has no `type="button"`.
- The conflict card prints the path twice (status sentence and path line), and the banner prints the page path under a heading that says "this page".

- `decided` in `wiki-page-view.tsx` equals `restored`.
- `library-history-panel.tsx` still has its own diff rendering next to the new `DiffLines`.
