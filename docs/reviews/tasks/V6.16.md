## Gap fixed

The README's desktop `docker run` uses `--cap-drop ALL`. On this host (Ubuntu 24.04 with `kernel.apparmor_restrict_unprivileged_userns=1`, Docker 29) Chromium cannot use a user namespace, falls back to its setuid sandbox and aborts at `sys_chroot`, so the daemon reported "the desktop is not available to agents". Adding `--cap-add SYS_CHROOT` fixes it, with the rest of the documented flags kept. `apps/computer/README.md` now has that flag and a sentence on why. `--cap-drop ALL` alone passes the local `test-desktop-image.sh`, since that script does not use the documented flag set (V6.3 nit).
