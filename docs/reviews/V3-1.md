### V3.15 Dry runs make no library home folder (finding 1)

Lane: worker. Executor: claude. Size: S.

Scope:
- In `apps/web/src/server/pi-run.ts` `#prepareRun`, skip `#ensureHome(input)` when `input.run.dryRun` is set. No other library write may happen at a dry run's start.
- If the isolate's library tools need the home to exist for reads, treat a missing home as empty in a dry run. Do not create it.

Check:
- `pi-run` test with a fake library: starting a dry run calls no `mkdir` (and no other library write), and a normal isolate run still creates the home.
- `bun run check && bun run test && bun run build` pass.
