The chip lookup still chunks ids by 100 (`use-file-infos.ts`), so a long session with many outputs does not break `files.describe`.

The rest of M7 is as round 1 found it. The only change to the files service since then is M5.1 stamping `source: "slack"` for a Slack user's upload (`packages/services/src/files.ts:106`), which has its own test. The build-plan checks for M7.1 are still covered by `files.test.ts`.
