# Harbourmaster

Harbourmaster is the name for Dom's agent platform vision, chosen on 16 October 2026. This folder also covers the wider AI operating system around it: Agentum (cloud agent platform on Claude managed agents), Bruce (an agent built on Claude Code, with a version on the Anthropic Agent SDK), the control plane that collects data and events from different sources, and Claude Code used via remote control.

The aim is a platform that makes it simple for an SMB to build and talk to an agent, and flexible enough for Dom to run his own agents on machines he controls.

This is the knowledge side. Tasks and delivery tracking live elsewhere. Pages here should answer why it is built the way it is.
