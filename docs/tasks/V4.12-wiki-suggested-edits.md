An agent without write access to a wiki page proposes an edit. A person accepts, edits first, or rejects it in Needs you.

## Scope
- `packages/services/src/wiki/suggestions.ts`: `suggest(principal, path, body, summary)` for a run principal stores the bytes at the suggestion blob key with `base_version_id` and a `wiki.suggestion` event; one pending suggestion per agent and page replaces the older one.
- `decide(principal, id, { accept | reject, body? })` for people: accept writes the (optionally edited) body as a new version authored by the agent and approved by the person; reject closes it; both emit `wiki.suggestion.decided`. If the page moved past the base version, the suggestion becomes `stale` and accept needs an edited body.
- A Needs you item provider for pending suggestions, with the diff inputs (base text and proposed text).
- tRPC `wiki.suggestions.list/get/decide`.

## Check
- `packages/services/src/wiki/suggestions.test.ts`: suggest, accept, accept with edit, reject, stale base, a second suggestion replacing the first, people-only decide.
- `bun run check && bun run test && bun run build` pass.
