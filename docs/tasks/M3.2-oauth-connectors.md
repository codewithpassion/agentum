From `docs/architecture/build-plan.html#m3`. Access lane. Reuse: Agentum `connectors/oauth.ts` with `schema.ts`, `url.ts` and its tests (copy). Paths are in `docs/architecture/reuse.html`.

## Scope

`oauth_states` table. Discovery (RFC 9728 and 8414), dynamic client registration with a manual client id and secret fallback, PKCE.

`/connect/:connectorId?as=user` and `?as=agent:<id>`: Clerk session required, creates the state row with `initiator_user_id`, redirects to the provider.

`/api/connectors/oauth/callback`: refuses unless the session user is the initiator, `return_to` same-origin path only, token exchange, credential row with `version = 1`. Re-authorise link, status. UI: Connect buttons, status badge, re-authorise.
