People enrol a computer, see both roles on one machine, and attach a computer to an agent from its profile.

## Scope
- `apps/web/src/routes/_app/settings.machines.tsx` and `components/machines/*`: each machine shows its roles with a status for each. "Add computer" mints a computer code and shows the `docker run` commands (headless and desktop) and the binary command. "Add computer role" on a daemon machine mints a code bound to it.
- `components/machines/enroll-dialog.tsx` gains the role choice.
- The agent profile's Computer side card (from V3): pick a computer for cloud and managed agents, with its status and desktop or headless shown. Machine agents show "This agent runs on <machine>".
- Plain words throughout: "computer", "desktop", "Runs the agent".
