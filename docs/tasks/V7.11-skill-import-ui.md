The UI for GitHub import, after trueforge's `ImportGithubSkillForm.tsx` (MIT) on shadcn and tRPC.

## Scope
- `apps/web/src/routes/_app/skills.index.tsx` and `components/skills/import-github-form.tsx`: repository URL, optional folder path and ref (branch, tag or sha), with inline validation from the shared rules. Import shows the resolved commit.
- `skills.$skillId.tsx`: a source line with the repo, path and pinned short sha linking to GitHub. When `latest_commit_sha` differs, show "Update available" with a compare link and "Review update", which calls `importUpdate` and opens the proposed version's diff.

## Check
- Dispatcher browser check against a public skills repo: import, pinned sha shown, and a simulated update notice leading to a proposed version.
- `bun run check && bun run test && bun run build` pass.
