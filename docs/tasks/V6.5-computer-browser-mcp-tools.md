The tools a cloud or managed agent uses on its computer and its browser. They are ported from agentum `modules/mcp/tools.ts` (computer_* and browser_*) and `takeover-tools.ts` as platform MCP tools behind ports. V6.11 wires the ports.

## Scope
- `packages/mcp/src/ports.ts`: a `ComputerPort` (exec, readFile, writeFile, listDir, desktopInput, screenshot, requestTakeover) and a `BrowserPort` (navigate, snapshot, click, fill, screenshot). Both return plain values and typed failures (`offline`, `desktop_unavailable`, `desktop_busy`, `human_in_control`, `timeout`).
- `packages/mcp/src/tools/computer.ts`: `computer_exec`, `computer_read_file`, `computer_write_file`, `computer_edit_file`, `computer_list_dir` and `desktop_input` (the v1 action list, capped at `DESKTOP_MAX_ACTIONS`). Also `request_human_takeover(reason)`, which returns at once with "end your turn" guidance. Register them only when the agent has a computer, and `desktop_input` and takeover only when it has a desktop.
- `packages/mcp/src/tools/browser.ts`: `browser_navigate`, `browser_snapshot`, `browser_click`, `browser_fill`, `browser_screenshot`.
- Port agentum `computer/output.ts` (truncation) and `computer/paths.ts` (path policy) into `packages/mcp/src/tools/computer-support.ts`.
- `packages/protocol/src/attachments.ts`: add `computerInstructions({ desktop })` beside `workspaceInstructions`. It is the agentum `anthropic/system-prompt.ts` computer paragraph (display `:99`, launch GUI apps in the background, then `desktop_screenshot`).

## Check
- `packages/mcp/src/tools/computer.test.ts` and `browser.test.ts`, with fake ports: tool lists per capability, argument limits, truncation, path policy, each failure becoming a readable tool error, and takeover returning the end-turn note. `packages/protocol/src/attachments.test.ts` covers the paragraph with and without a desktop.
- `bun run check && bun run test && bun run build` pass.
