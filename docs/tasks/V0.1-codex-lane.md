Asked for by Dom on 26 Oct 2026. v2 uses Codex as a second implementation lane (`executor: codex`, see `docs/workflow.md`). On this host Codex's bwrap sandbox fails (`loopback: Failed RTM_NEWADDR: Operation not permitted`), and a `codex exec` run on 26 Oct could not write files. Dom wants the sandbox off, or under our control, so Codex jobs never hang on approvals or fail on network and file writes.

## Scope

- Add `scripts/codex-task.sh <worktree> <brief file> <log dir>`. It runs `codex exec` in the worktree with no sandbox and no approval prompts (`--dangerously-bypass-approvals-and-sandbox`, `-C <worktree>`, model `gpt-6.1-sol`, reasoning effort medium), reads the brief from the file, writes JSONL events to `<log dir>/codex.jsonl` and the final answer to `<log dir>/last-message.md`, and stops the job after 90 minutes with `timeout`. It prints one line at the end: exit code, whether the usage limit was hit (grep the log for ChatGPT's usage-limit message), and the last-message path.
- The script refuses to run unless `<worktree>` is under `/home/roboto/devel/harbourmaster-wt/` and is a git worktree. That keeps an unsandboxed Codex inside a disposable checkout.
- Don't use the openai-codex Claude plugin (1.0.6 is upstream, not the `codewithpassion/codex-plugin-cc` fork, and it passes its own sandbox flags). The plain CLI is easier to control.
- Note in `docs/HANDOVER.md` "Session setup notes" how Codex runs and why the sandbox is off. With the sandbox off, Codex runs as Dom's user with network access, limited only by the brief's rules and the worktree check.
- Smoke test: a trivial real change in a fresh worktree (for example, a missing unit test for a pure helper in `packages/services`) through the script, with the Codex brief template from `docs/workflow.md`.

## Check

- The smoke job ends with at least one commit on its branch, made by Codex, and `last-message.md` written.
- Inside the job, Codex ran `bun install` (network) and a D1-backed test in `packages/services` (local Miniflare writes) without errors.
- The script refuses a path outside `harbourmaster-wt/`.
- A job given a brief that loops is killed by the 90-minute limit (test with a 1-minute limit).
