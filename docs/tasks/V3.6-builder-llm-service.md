"Describe it in words and the builder drafts the profile." This task asks Claude for the draft JSON, with the workspace's own connectors, skills and agents as the only choices, and returns it reconciled with its gaps.

## Scope
- New `packages/services/src/agent-builder/service.ts` `createAgentBuilderService({ db, managedKeys, connectors, skills, agents, machines, fetch, clock })`, built in `compose.ts`.
- `catalog(principal)`: builds `BuilderCatalog` from the existing services.
- `draft(principal, { description, voicePreset?, templateId?, previous?, locked? })`: one Anthropic Messages API call using the workspace's Anthropic key (resolved through `managedKeys` the way `pi-run-credentials.ts` does) and a forced tool whose input schema is the draft schema. The catalogue goes in the prompt as names and ids. The output goes through `reconcileDraft`. No key gives `ServiceError("invalid", NO_KEY_MESSAGE)`. A model error or invalid JSON is retried once, then reported.
- The description is capped at 8 000 characters. Drafting logs no event (the agent doesn't exist yet), and the description is never logged.
- The default model is `CLOUD_DEFAULT_MODEL`. Inject `fetch` so tests use a fake.
- New thin `apps/web/src/server/trpc/agent-builder-router.ts` with `catalog` and `draft`.

## Check
- `agent-builder/service.test.ts` with a fake fetch: the request carries the catalogue and the forced tool; a reply naming an unknown connector comes back as a gap; locked fields are kept; no key gives the message; one retry on bad JSON.
- `bun run check && bun run test && bun run build` pass.
- Live (controller, staging): describing the Researcher from the mock gives a draft with Web search, a monthly routine and the "Where it runs" gap.
