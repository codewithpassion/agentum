The one-page profile reads every row in one call instead of the eight tabs' separate queries. The "Ask me before it…" toggles read and write V1's approval rules for the agent.

## Scope
- New `packages/services/src/agent-profile.ts` `createAgentProfileService`, built in `compose.ts` from the existing services, not new queries where a service already answers.
- `profile(principal, agentId)` returns the header (name, slug, runtime, model, machine, status, `email_local`, a waiting run if any) and these rows:
  - Does and Voice: instructions and soul.
  - Tools: assigned connectors from `connectors.ts` assignments, plus granted secrets as hidden chips from `secrets.ts`.
  - Skills: assigned skills, marking a proposed version.
  - Hands to: `hands_to`. Receives from: the agents whose `hands_to` names this one.
  - Starts on: triggers, routines, and the Slack app mention.
  - Channels: the Slack app's status. Email shows as "reserved" until V5.
  - Library: `agents/<slug>/` as home and `libraryPaths` from runtime config, shown read and write. Enforcing access is V4's.
  - Recent tasks: `tasks.list({ agentId, limit: 5 })` from V2.9.
- Ask before: `askBefore(principal, agentId)` lists the agent's gateable actions (connector tools that aren't read-only and the built-in side-effect tools V1 gates), each with a plain label ("Xero: create bill") and its V1 rule (ask, or always allowed). `setAskBefore(principal, agentId, action, ask)` writes through V1's rule service.
- New thin `apps/web/src/server/trpc/agent-profile-router.ts`, added to `runtime-router.ts`.
