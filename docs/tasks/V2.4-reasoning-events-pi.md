Cloud runs drop Pi's `thinking` parts (`eventOfPart` in `apps/web/src/server/pi-run-events.ts` returns nothing for them). The thread's reasoning container and the action log's thoughts need them. If V1 already records reasoning for cloud runs, close this task at planning.

## Scope
- `apps/web/src/server/pi-run-events.ts` `eventOfPart`: a non-empty `ThinkingContent` part becomes `message.reasoning` with `{ text }`, in order with the text and tool calls of the same message.
- Redacted or signature-only thinking becomes nothing.
- Make sure V1's live stream publishes the new event the way it publishes `message.assistant` from `PiRun`.

## Check
