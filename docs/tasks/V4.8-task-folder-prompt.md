Agents hand files back by writing them to `agents/<agent>/tasks/<id>/`, not by putting markers in the answer. This changes the shared prompt builder all runtimes use.

## Scope
- `packages/protocol/src/attachments.ts`: `WorkspaceInstructionsInput` gains `taskFolder` (a local path, or a library path for runtimes without a local copy) and the marker sentence is replaced by "Save files for the user in <taskFolder>. Everything there shows in the task's Files panel." Library lines name the access mode of each root.
- Remove `formatAttachmentMarker`, `attachmentInstructions` and `extractAttachmentMarkers`. Keep `stripAttachmentMarkers` so old transcripts still render clean.
- Rename the file to `packages/protocol/src/workspace-instructions.ts` only if every importer is updated in this task; otherwise leave the name.

## Check
- `packages/protocol/src/attachments.test.ts`: the prompt names the task folder and the modes, has no marker sentence, and `stripAttachmentMarkers` still cleans old text.
- `bun run check && bun run test && bun run build` pass (callers compile because `taskFolder` is optional until V4.5, V4.7 and V4.9 pass it).
