Cloud agents (PiRun, in an isolate or the Linux VM) use the computer tools over the platform MCP and see the desktop through a native Pi tool that returns an image.

## Scope
- `apps/web/src/server/pi-run.ts` and `pi-run-core.ts`: when the agent has `computer_machine_id`, register a Pi `desktop_screenshot` tool that calls the relay port and returns an image content block. Add `computerInstructions` to the prompt.
- A take-over request ends the turn and leaves the run waiting. The hand-back resume from V6.7 continues the PiRun with the note.
- `compose.ts`: pass `desktopScreenshot` from the relay port to the managed service (V6.12), and implement `requestTakeover` in `computer-ports.ts` over the takeover service (V6.7).

## Check
- `pi-run-core.test.ts`: the tool is present only with a desktop computer, the image block reaches the model call, the offline result, the prompt paragraph, and takeover then resume.
- `bun run check && bun run test && bun run build` pass.
