The desk becomes the home page: Needs you, Running and Done today, each card with its one-sentence band, following `hm-unified/project/Main.dc.html`.

## Scope
- `apps/web/src/routes/_app/desk.tsx`: loader calls `desk.get` with the browser's local midnight. Header with date and agent count, agent filter chips ("All agents" plus one per agent), "+ New task" and "+ New agent".
- New `apps/web/src/components/desk/` (lane, card, band, needs-you card): band colours by tone (ok, waiting, running, error); cards link to `/tasks/$runId` or the inbox thread.
- Needs you cards reuse V1's approval and question card components inline (Allow once / Always allow / Deny, or the answer chips), and Approve / See changes / Reject for skill, trigger and routine proposals through their existing tRPC calls.
- "+ New task": a dialog to pick an agent and type the request. It calls `runs.start` with a `ui` session and goes to the task view.
- Refresh: refetch every 10 s while the tab is visible and on focus, with `components/inbox/use-polled-query.ts`. No workspace stream in V2.
- Sidebar badge reads `desk.needsYouCount`.
