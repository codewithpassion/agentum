With the task thread in place, the agent page's Chat tab and its polling are dead weight. This task removes them and points every "open chat" path at the task view.

## Scope
- Delete `apps/web/src/components/agent/tabs/chat.tsx`, `chat/chat-logic.ts` (`POLL_MS`, `shouldPoll`, `toChatItems`) and `chat/transcript-view.tsx` with their tests. Keep `upload-file.ts`, `library-picker.tsx`, `save-to-library.tsx` and `file-chips.tsx` if the thread uses them, else delete the orphans too.
- `components/agent/agent-tabs.ts` drops `chatTab`. `openSession` in `routes/_app/agents.$agentId.tsx` and the Sessions tab open `/tasks/$runId` for the session's latest run. The agent header gets "Run now", which opens the New task dialog with the agent picked.
- `routes/_app/sessions.tsx` and `components/sessions/session-list.tsx` link each session to its latest run's task view. `session-transcript.tsx` goes if nothing else uses it.
- Grep the repo (Slack links, MCP tool results, inbox) for `tab=chat` and `?session=` URLs, and repoint them to `/tasks/<runId>`.
