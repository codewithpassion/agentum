## Scope
- The Library row lists the home folder (always read and write), the wiki (read, suggestions), and each grant with a Read only / Read and write toggle and remove. "Add folder" picks a library folder.
- Calls `library.access.*`; the note under the row says that on a machine or VM these folders sync live, and each task writes to its task folder.
- Any remaining `libraryPaths` editing in the old runtime config UI goes.
