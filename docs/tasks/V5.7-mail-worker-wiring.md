Connects the mail service to Cloudflare: mail in, mail out, routing rules.

## Scope
- Inbound: the Worker's `email()` handler in `apps/web/src/server.ts` (Option A) or an RPC entrypoint the inbox Worker calls (Option B) parses with PostalMime and calls `mail.receive`.
- `apps/web/wrangler.jsonc`: the mailbox DO class and migration tag or the service binding, `send_email`, and `MAIL_DOMAIN`, each in the top level, `env.staging` and `env.staging.previews`. `.env.example` lists the Cloudflare API token secret for Email Routing.
- New `apps/web/src/server/email-routing.ts`: `EmailRoutingPort` over the Cloudflare Email Routing rules API.
- `compose.ts`: build the mail service; `apps/web/src/server/mcp/ports.ts`: real adapters for the V5.8 tools; the V1 approval decision hook calls the V5.5 handler.
