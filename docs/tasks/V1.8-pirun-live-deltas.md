Stored events reach the stream through V1.4, but cloud runs can do better: Pi commits the partial answer every 100 ms (`viewState` `docs["pi.live"]`, see the pi-durable README "Watching a Conversation"). This task sends that text as `delta` frames so a cloud agent's reply appears as it is written.

## Scope
- In `apps/web/src/server/pi-run.ts` `#port().watch`, also read the running generation's streamed partial text from the view and hand it to a new `deltaPublisher` in `pi-run-deltas.ts` (logic testable in bun): at most one frame per 250 ms per run, carrying the full partial text so far under a `messageKey` stable for that assistant message.
- Secrets: the text goes through the run's masker (`secrets.maskerFor`) and `redactText` from C.19 before it leaves the object. Because each frame holds the whole partial text, a secret split across two chunks is still masked. Tool-call arguments and tool output are never streamed as deltas; they appear only as the stored, scrubbed `tool.call` and `tool.result` events.
- Publish through the `SessionStream` binding (`streamPublisher` from V1.4). A failed publish is dropped quietly.

## Check
- `pi-run-deltas.test.ts`: throttling with a fake clock, the full text in each frame, a granted secret's value and an `sk-` token masked even when split across two partials, no frame for a tool call.
- `pi-run-core.test.ts` still passes; `bun run e2e:pi-durability` still passes.
- `bun run check && bun run test && bun run build` pass.
- Live on staging (controller): with V1.6 deployed, a cloud agent's long answer grows on the chat page before the run ends.

## Refinements (26 Oct 2026, against main)

Checked against the code before V1 started. Where these differ from the scope above, they win.

- `#port().watch` subscribes to `session.events()` filtered by `COMMIT_EVENTS` and reads no view. Subscribe to the session's `viewState()` (pi-durable README, "Watching a Conversation") and read `docs["pi.live"]` for partial text.
- Add `./events/scrub` to the `exports` of `packages/services/package.json` so `apps/web` can import `redactText`.
