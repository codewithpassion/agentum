From `docs/architecture/build-plan.html#m1`. Builds on M0.4 (runs service) and the M0.7 shell. Reuse: the flightdex shell pattern, and the shadcn message components already in the repo.

## Scope

In the shell from M0.7:

- Agents list, create and edit (name, instructions, model, runtime `machine` or, in dev, `fake`, machine picker).
- Agent page chat tab: input box, transcript rendered from `sessions.transcript`, polling every 1.5 s while a run is active, a run status line, and Retry on an interrupted run, enabled only after `process_ended_at` or ten minutes.
- Machines page with an enrol button that shows the enrol command.
- Sessions list per agent.

## Check

A dev-login browser script (agent-browser or claude-in-chrome): open `/login`, click Dev login, create agent "Pelican", open it, send a message, and see the reply within 60 s.
