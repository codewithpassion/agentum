## Scope
- Deploy staging. Enrol one Docker desktop computer, and add the computer role to a machine that already runs the daemon, so one machine serves both roles.
- A cloud agent and a managed agent each with a computer: run `computer_exec`, open Chromium, call `desktop_screenshot` and describe the page.
- An agent calls `request_human_takeover`. The card shows in Needs you, Slack pings with a working "Open screen" link, a person takes over in the task view, types, and clicks I'm done with a note, and the agent resumes with the note.
- `browser_navigate`, `browser_snapshot` and `browser_screenshot` on Browser Run, with the screenshot in the task's Files panel.
- Revoke the machine: every socket closes and both roles show revoked.
