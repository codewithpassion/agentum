The contract for V3. It holds every schema change the profile, the builder and the dry run need. No other V3 task touches `packages/db/src/schema` or generates a migration.

## Scope
- `packages/db/src/schema/agents.ts`: `soul` (text, not null, default `''`), `hands_to` (JSON array of agent ids, default `'[]'`), `email_local` (nullable text, the reserved local part, with a unique index on `(workspace_id, email_local)`). The mailbox and domain are V5's.
- `AGENT_STATUSES` gains `draft`: a builder agent that is not created yet. Lists, the desk, Slack and triggers ignore drafts.
- `packages/db/src/schema/runs.ts`: `dry_run` (boolean, default false).
- `EVENT_TYPES`: `agent.address_reserved` and `run.dry_run_skipped` (payload `{ tool, summary }`: what the run would have done, with no secret values). Add both payload shapes to `packages/services/src/events/payload.ts`.
- Shared in `@repo/db/shared`: `VOICE_PRESETS` (brief, careful, friendly, formal), `AGENT_TEMPLATE_IDS` (sort_inbox, chase_invoices, research_topic), `PROFILE_FIELDS` (does, voice, rules, tools, skills, starts_on, hands_to, runs_on, library, address) and `ProfileGap { field, question }`.
- Add a `dry_run` session origin in `packages/services/src/runs/types.ts` `SESSION_ORIGINS`.
- Run `bun run generate` in `packages/db` and commit `migrations/` with `meta/`. The migration only adds columns and an index, so no table is recreated.

## Check
- `packages/db` test: the migration applies on a fresh `migrated()` database, existing agents get `soul = ''` and `hands_to = '[]'`, and a second agent with the same `email_local` in one workspace fails while one in another workspace succeeds.
- `bun run check && bun run test && bun run build` pass.
