Drag, wire and plug on the same canvas.

## Scope
- In Editor mode nodes drag, and positions save with a debounce through `map.savePositions`.
- Drawing a wire from a trigger to an agent calls `connectTrigger`, and deleting a wire disconnects after a confirm. Only valid connections are offered (`isValidConnection`).
- A tool palette in the side panel. Dropping a tool on an agent's port calls `plugTool`, and removing a port chip unplugs it. A tool that needs setup (an unconnected connector, a computer not enrolled) links to its setup page.
- "+ Trigger" opens the existing trigger form, and "+ Agent" opens the V3 new-agent flow. New nodes appear where they were dropped.
- The inspector in Editor mode shows the same profile rows, editable, and links to the full profile.

## Check
- Dispatcher browser check: drag and reload keeps the position, wire a trigger and see it on the agent profile's Starts on row, plug a tool and see it on the Tools row, and delete a wire.
- `bun run check && bun run test && bun run build` pass.
