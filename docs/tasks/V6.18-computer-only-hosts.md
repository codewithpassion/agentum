From the V6 gate review (`docs/reviews/V6-1.md`).

Scope
- `packages/services/src/agents.ts`: `assertMachineInWorkspace` (create and update of a machine agent) refuses a machine without the `agent_host` role with an `invalid` error, using the same test as `rolesOf` in `machines.ts` (export a small helper from the machines module rather than repeating the prefix).
- `packages/services/src/agent-builder/service.ts`: `usable` keeps only machines whose `roles` include `agent_host`, so the builder offers neither those machines nor the `machine` runtime from a computer-only machine.
- `apps/web/src/components/agent/agent-form.tsx`: `selectable` keeps only machines with the `agent_host` role.
- Coordinate with V7: `apps/web/src/components/map/tool-palette.tsx` lists machines too and may need the same filter, but it is a V7 file in the web lane, so note it there rather than change it here.

Check
- Service tests: creating or updating a machine agent on a computer-only machine fails, and on a dual-role machine succeeds. The builder test lists a computer-only machine nowhere and offers no `machine` runtime when it is the only machine.
- `bun run check && bun run test && bun run build` pass.
