The n8n-style map from the agreed Map screen (hm-unified `Map.dc.html`), Runs mode first. It uses `@xyflow/react`, which master-control's `agent-network-graph.tsx` used.

## Scope
- Route `apps/web/src/routes/_app/map.tsx` and a nav entry. The `Editor | Runs · last 7 days` toggle has Runs on by default, plus Fit view.
- `apps/web/src/components/map/`: custom nodes for a trigger (pill), an agent (tile, name, runs, runtime, tool ports, status) and an output (Slack, Library, Q&A with its open count). Wires are green when active and grey when idle, with a count label. A waiting agent node is yellow with a badge.
- Inspector panel on node click. An agent shows what is plugged in (model, tools, computer, skills, secrets hidden), its last run, an approval inline when waiting (V1's Allow once / Always allow / Deny) and Open task. A trigger and an output show their recent items.
- Positions are read-only in Runs mode. The graph refreshes on V1's live stream or on a short interval, so a new waiting state shows without a reload.
- Add `@xyflow/react` to `apps/web`, styled to the app's tokens in light and dark.

## Check
- Unit tests for mapping `MapGraph` to xyflow nodes and edges. Dispatcher browser check: nodes, counts, a yellow waiting node, the inspector with an inline approval that works, Fit view.
- `bun run check && bun run test && bun run build` pass, and the bundle grep for `drizzle` finds nothing.
