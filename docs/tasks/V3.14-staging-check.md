Proves on staging that an agent can be described, dry-run and created, and that its profile drives what it does.

## Scope
- Deploy to staging with `staging:deploy` (controller). Sign in with `bun run agent-login --env staging`.
- Build the Researcher from the mock: the draft picks existing connectors and skills only, flags "Where it runs", and reserves `research`. The dry run shows reads done and writes skipped. Create agent.
- On the new profile: change the voice and run a task, and the reply follows the voice on cloud, machine and managed agents. Turn on "Ask me before it…" for one write tool and see the approval in Needs you.
- Fix wiring gaps under 50 lines here. Anything bigger becomes a new V3 task.
