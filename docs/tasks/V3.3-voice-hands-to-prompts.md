The profile's Voice (soul) and Hands to rows must change what the agent does, not just what the page shows. This task makes them editable and puts them in the system prompt for every runtime.

## Scope
- `packages/services/src/agents.ts`: `agentCreateSchema` and `agentUpdateSchema` take `soul` (max 10 000 characters) and `handsTo` (agent ids). `handsTo` must name active agents in the same workspace and not the agent itself, else `ServiceError("invalid")`. `AgentRecord` carries both.
- New pure `packages/services/src/agent-prompt.ts` `agentPrompt(agent, handsToNames)`: instructions, then a "Voice" section when the soul is set, then "You can hand work to: <names> (use send_message)" when `handsTo` is set.
- Use it in the three places that compose instructions today: `cloud/runtime.ts` (line 68), `runs/machine-claim.ts` (line 251) and `managed/service.ts` (line 172). Managed agents re-sync when soul or `handsTo` changes, the way they do for instructions.
- `agent.updated` events record which fields changed, never the soul text.

## Check
- `agent-prompt.test.ts`: no sections when both are empty, Voice only, Hands to only, both.
- `agents.test.ts`: validation for `handsTo` (self, another workspace, an archived agent).
- `cloud`, `machine-claim` and `managed` tests: the composed instructions contain the voice.
- `bun run check && bun run test && bun run build` pass.
