Suggested edits and conflicts land in the desk's Needs you lane, and on the page they concern.

## Scope
- Suggested edit card (desk Needs you and the wiki page banner): agent, page, summary, inline diff (the V4.15 diff helper), Accept, Edit first (opens the editor with the proposed text), Reject. A stale suggestion says so and offers Edit first only.
- Conflict card: path, agent, task link, Compare, Keep library version, Keep agent version.
- Each card has its one-sentence status band like the other desk cards, and leaves the lane when decided anywhere.

## Check
- Logic tests for card status text in the desk's card helpers.
- Browser check (dispatcher, local dev, seeded rows): accept, edit-then-accept and reject a suggestion; resolve a conflict both ways; the card disappears.
- `bun run check && bun run test && bun run build` pass.
