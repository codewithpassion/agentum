The last builder step: run the draft on a sample with nothing saved or sent, read the result as a receipt, then create the agent.

## Scope
- New `components/agent/builder/dry-run-panel.tsx`: "Dry run on a sample. Nothing is saved or sent." The sample input is key chips from the draft's sample, editable. Run calls `agentBuilder.dryRun` and follows the run on V1's stream. The result renders with V2's `Receipt` component, and `run.dry_run_skipped` events show as "Would …" lines.
- "Run the dry run again" and "Create agent". Create is disabled while gaps other than the address remain, and says why.
- Create calls `agentBuilder.create` and goes to the new profile. "Discard" calls `discard`.
- Say on the panel that the dry run uses Cloudflare whatever runtime is chosen.

## Check
- Browser (dispatcher, locally with a cloud agent and a provider key): a dry run of a draft with a write tool shows "Would …" and leaves the library and Slack untouched; create lands on the profile with tools, skills, schedule and address set; the dry run is not on the desk.
- `bun run check && bun run test && bun run build` pass.

## Refinements (2026-10-26)

Checked against main at ae74008. Where these differ from the scope above, they win.

- Before the first dry run, call `agentBuilder.saveDraft` (V3.7) to get `draftAgentId`, and call it again when the draft changed. Reserve the address through `agents.reserveAddress` on create, or let `create` fall back to `suggestAddress`.
- Following the run: `use-session-events.ts` and `session-events-logic.ts` in `components/task/` (V2.11) take the dry run's session. `tasks.get` serves the dry run, because V3.7 filters lists but not `sessions.get`. Render the steps with `components/task/receipt.tsx` and `buildReceipt`. `run.dry_run_skipped` is in `STREAM_EVENT_TYPES` (V3.1) and its payload is `{ tool, summary }`.
- After create, `router.invalidate()`, so the sidebar's agent list shows the new agent (V2.7 did the same for `agents.new.tsx`).
- Plan default: the dry run always runs on the cloud isolate.
