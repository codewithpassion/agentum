- New `components/agent/builder/dry-run-panel.tsx`: "Dry run on a sample. Nothing is saved or sent." The sample input is key chips from the draft's sample, editable. - Create calls `agentBuilder.create` and goes to the new profile. "Discard" calls `discard`.
