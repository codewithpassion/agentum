People run a computer with one `docker run`. This task ports agentum's two images and its publish workflow.

## Scope
- `apps/computer/Dockerfile` is the headless daemon. `Dockerfile.desktop` adds Xvfb, openbox, Chromium, xdotool and xclip on display `:99`, as in agentum.
- `scripts/test-desktop-image.sh` builds the desktop image, starts it and checks that a screenshot op works against a local fake relay.
- `.github/workflows/computer.yml` publishes `ghcr.io/<owner>/harbourmaster-computer` and `-desktop`, tagged `latest` and the commit. `workflow_dispatch` is its only trigger (docs/workflow.md "GitHub"), with no push and no path filter.
- README "Docker" section: the enrol command, then `docker run` with the state volume, for headless and desktop.

## Check
- `docker build` succeeds for both images locally, and `scripts/test-desktop-image.sh` passes.
- `bun run check && bun run test && bun run build` pass.
- Controller: Dom runs the workflow once by hand and the two images appear on ghcr.
