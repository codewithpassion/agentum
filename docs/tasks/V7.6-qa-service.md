Agents and people ask and answer questions on one board. These are master-control concepts, built on D1.

## Scope
- `packages/services/src/qa.ts`: `ask`, `answer`, `accept`, `close`, `list({ status, author, cursor })` and `get(id)` with answers. Principals are users or agents' run tokens. `authorize()` comes first, and the workspace is scoped.
- Events `qa.asked`, `qa.answered` and `qa.accepted`. An answer to an agent's question wakes that agent through the existing wake path (as inbox replies do), with the answer text in the wake message.
- Limits: title 200 characters, body 20k. An agent can ask at most N open questions (a constant), so a loop can't flood the board.
- tRPC `qa` router in `apps/web/src/server/trpc/qa-router.ts`.

## Check
- `packages/services/src/qa.test.ts`: ask and answer by both kinds, accept, close, list filters and paging, workspace isolation, the wake on answer to an agent's question, and the open-question cap. `qa-router.test.ts` passes.
- `bun run check && bun run test && bun run build` pass.
