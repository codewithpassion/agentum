The library page today does not refresh and has no history or move UI. This brings it to the agreed Library screen for files.

## Scope
- `apps/web/src/routes/_app/library.tsx`: refresh the listing and the open file when `library.*` events for the workspace arrive over the live stream from V1 (fall back to a 10 s refetch if the page has no stream).
- `apps/web/src/components/library/library-file-panel.tsx`: a History panel (version, author, time, op), Compare any two versions with a line diff (pure helper in `library-logic.ts`), Restore with confirm.
- `library-toolbar.tsx` / `library-list.tsx`: Move and Rename dialogs calling `library.move`, with the error shown when the target exists.
- Use shadcn components through the CLI only (`components/ui/` is never hand-edited).
