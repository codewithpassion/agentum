## Scope
- Copy `cmd/`, `internal/{agent,audit,conn,desktop,enroll,files,policy,protocol,runner,serverurl,state}`, `packaging/` and `scripts/` into `apps/computer`. Rename the module and binary to `hm-computer`, and the systemd unit to `hm-computer.service`.
- Enrol through `POST /api/machines/enroll` with an `hm_enr_` code and role `computer` (the V6.1 schema). Store the returned `hm_mach_` credential in the state dir with the same file modes as before.
- Dial `GET /api/machines/computer` (an outbound WebSocket with Bearer auth). Leave the frames, heartbeat literals, close codes and chunk sizes unchanged: protocol v1 is frozen.
- `internal/protocol` tests read the shared fixtures in `apps/computer/testdata/protocol/`, so Go and TS agree byte for byte.
- `apps/computer/package.json` gets `test` and `check` scripts that run `go test ./...`, `go vet` and the fmt check, so turbo runs them. Skip cleanly with a message when `go` is missing.
- Update the README for Harbourmaster names, URLs and the enrol flow. Leave Fly out, and add one line saying Podman should work the same as Docker but is untested.
