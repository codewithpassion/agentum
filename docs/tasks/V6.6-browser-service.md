The browser module, ported from agentum `modules/browser/{rules,snapshot,service,activity}.ts`. Every agent gets a browser that needs no computer. The Playwright adapter stays outside the service (V6.11).

## Scope
- `packages/services/src/browser/`: `rules.ts` (URL and selector limits, the SSRF guard, `KEEP_ALIVE_MS`), `snapshot.ts` (aria snapshot formatting) and `service.ts`. The service takes a `BrowserDriver` port (launch, connect by session id, page actions) and persists the session row in `browser_sessions`, so the next call reconnects to the same page.
- Screenshots are saved into the run's task output folder in the library through the library service (from V4), so they show in the Files panel. No separate screenshots table.
- Each action writes a `browser.action` event (action, host, outcome), never page content.
- Export the module's public API through its `index.ts`.

## Check
- `packages/services/src/browser/*.test.ts`: rules (private addresses, schemes, lengths), snapshot formatting, session reuse and relaunch after a stale id with a fake driver, the screenshot landing in the task folder, and the event shape.
- `bun run check && bun run test && bun run build` pass.
