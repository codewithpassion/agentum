When an agent asks for a take-over, the person hears about it in Slack with a link straight to the screen.

## Scope
- In the Slack module that posts V1's pending-request cards (packages/services/src/slack*), add a card for kind `takeover`. It shows the agent's name and reason, an "Open screen" button linking to the task view's screen anchor, and a "Cancel request" action that settles through V1's generic pending-request settle. It posts in the agent's thread, or the person's DM when the task has no thread.
- When the request is settled anywhere, the card is updated to show "Handed back by <name>" or "Cancelled", the same way approval cards update.
- No take-control from Slack: control needs the browser.

## Check
- Slack module tests: Block Kit for an open, handed-back and cancelled take-over, the link URL, the thread versus DM target, and the cancel action calling the settle function.
- `bun run check && bun run test && bun run build` pass.
