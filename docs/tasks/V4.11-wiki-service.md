The wiki lives inside the library: a page is a markdown file under `wiki/`, with versions from V4.2. This task ports the link handling from agentum and keeps a link index for backlinks.

## Scope
- New portable module `packages/services/src/wiki/` with an `index.ts` barrel. Port `wiki-links.ts`, `slug.ts` and `heading-anchors.ts` with their tests from `/home/roboto/devel/agentum/apps/web/src/modules/wiki/`. Take the page tree by folder (parent pages) and broken-link styling as concepts from master-control `packages/backend/convex/wiki.ts`.
- Link resolution: `[[Finance/Month-end]]` resolves to the page `wiki/finance/month-end.md`; otherwise to the library path as written (`[[files/invoices]]`); otherwise it is broken.
- The library service takes an optional `linkIndex` dependency that returns the `library_links` statements for a write, move or delete of a `wiki/**.md` file, so the index changes in the same `atomic` batch.
- Service: `pages(principal)` as a tree, `page(principal, path)` with body, title (first `# ` heading or file name), resolved links with a `broken` flag, and backlinks; `createPage(principal, title, parent)`.
- tRPC `apps/web/src/server/trpc/wiki-router.ts` with `pages`, `page`, `createPage`, mounted in `router.ts`. V4.21 builds the service in `compose.ts` (worker lane); until then the router tests use the factory directly.

## Check
- Ported tests pass in `packages/services/src/wiki/*.test.ts`. `wiki/service.test.ts`: a link to a missing page is broken and turns live when the page is created; backlinks update on edit, move and delete; a link to a library file resolves.
- `bun run check && bun run test && bun run build` pass.
