Connects the V7 services to the MCP server and the minute tick.

## Scope
- `apps/web/src/server/mcp/qa-ports.ts` implements `QaPort` over the Q&A service with the run's principal.
- `compose.ts`: build the Q&A service, and pass the GitHub fetcher from V7.9 to the skills store.
- `apps/web/src/server/tick/automation.ts`: a `skills-github-updates` job that calls `checkUpdates` on a small batch, oldest `checked_at` first, so each skill is checked about every 6 hours.

## Check
- `qa-ports.test.ts`, and a tick test that the job is registered and calls `checkUpdates` with the batch.
- `bun run check && bun run test && bun run build` pass.

## Refinements (2026-10-27)

Checked against main at 24c28ad. Where these differ from the scope above, they win.

- depends_on adds V6.11: V6.11 passes `browser: true` for every run principal in `routes/mcp.ts`, and this task changes that line.
- The Q&A service is built in `compose.ts` by V7.6, so this task does not build it.
- Ports: `qa-ports.ts` in `apps/web/src/server/mcp/`, joined into the port object in `mcp/ports.ts` (where `inboxList` and V6.11's adapters live). `routes/mcp.ts` passes `qa: true` for every principal.
- Browser switch (V7.4): `routes/mcp.ts` passes `browser` only when the run's agent does not have `runtimeConfig.browser === false`.
- GitHub: `compose.ts` passes the V7.9 fetcher and `env.GITHUB_TOKEN` (optional) to the skills store. Add `GITHUB_TOKEN=` to `apps/web/.env.example` with a comment, and run `wrangler types`. It is a secret, not a binding, so `wrangler.jsonc` does not change.
- Tick: the job goes in `tick/automation.ts`, which no V4 to V6 task edits (V4.6 adds `tick/library.ts` and edits `jobs.ts`). Unauthenticated GitHub allows 60 API requests an hour per IP, and Worker egress IPs are shared. Plan default: `checkUpdates` with a batch of 2, and the job runs only when the tick minute is a multiple of 5 (about 24 calls an hour, under the limit). That checks 576 skills a day, so each skill about every 6 hours up to about 140 sourced skills.
- Same-file overlaps in the worker lane: `compose.ts` with V4.6, V4.21, V5.7, V6.11 and V6.13; `mcp/ports.ts` and `routes/mcp.ts` with V4.21, V5.7 and V6.11; `.env.example` with V5.7.
