Rules are stored per tool, but each runtime names tools differently: Claude Code says `Bash` and `mcp__github__create_issue`, Pi says `bash` and `github_create_issue` (`piToolName` in `apps/web/src/server/pi-run-mcp.ts`), Managed Agents say `bash` or an `mcp_tool_use` with a server name. This task gives every runtime the same pure functions, so a rule set on one agent means the same thing on all three.

## Scope
- In `packages/protocol/src/requests.ts` (schemas from V1.1), add functions only:
  - `toolKey({ runtime, name, server? })`: MCP tools become `<serverKey>/<tool>` (server keys as `mcpServerUrls` makes them: `harbourmaster`, connector slugs). Claude Code's `mcp__<server>__<tool>` and Pi's `<server>_<tool>` are split by the known server keys passed in. Built-in tools map to one lowercase name across runtimes through a table: `Bash`/`bash` to `bash`, `Write`/`write` to `write`, `Edit`/`MultiEdit`/`edit` to `edit`, `Read`/`read` to `read`, `WebFetch`/`web_fetch` to `web_fetch`, `WebSearch`/`web_search` to `web_search`, `run_script`, `run_skill_script`. Unknown names pass through lowercased.
  - `ASK_USER_TOOL`: name `ask_user`, a description telling the agent to ask only when it can't go on without a person, and the JSON schema of one question (`question`, optional `choices`, `multiSelect`). The cloud and managed runtimes register it from here.
  - `isAskUserCall(runtime, name)`: true for `ask_user` and Claude Code's `AskUserQuestion`.
  - `approvalSummary(toolName, input)`: one line for cards ("Run `git push origin main`", "Call github/create_issue"), capped at 200 chars. Input is already scrubbed by the caller.
  - `outcomeText(kind, outcome)`: what the model gets back. Approval: allowed returns null (the tool runs); deny gives "A person denied this call." plus the note; expired gives "Nobody answered within the time limit, so the call did not run.". Question: the answers as "Q: … A: …" lines; expired gives "Nobody answered the question in time. Go on without it or stop and say what you need."; cancelled gives "The question was withdrawn because the run is ending."
  - `askUserQuestionAnswers(input, answer)`: turns a question answer into the `answers` map Claude Code's `AskUserQuestion` input expects (question text to answer, multi-select joined with ", ").
