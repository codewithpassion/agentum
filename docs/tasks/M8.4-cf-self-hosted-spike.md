Approved by Dom on 17 Oct 2026. Anthropic's self-hosted sandboxes (public beta, https://platform.claude.com/docs/en/managed-agents/self-hosted-sandboxes) let a Managed Agent run its tools on our own infrastructure. Cloudflare's template `cloudflare/claude-managed-agents` (alpha, https://github.com/cloudflare/claude-managed-agents) is a Workers control plane that runs a Sandbox SDK microVM per session.

## Questions

1. Can Harbourmaster create a `self_hosted` environment per workspace key and point managed sessions at it, beside today's `cloud` environment, chosen per agent?
2. Does the template work as is, or should its sandbox half live in Harbourmaster next to C.14's Linux VM backend? Compare one shared VM backend for cloud and managed agents against a separate template Worker.
3. Do Anthropic Skills API skills (M8.3) mount in the self-hosted sandbox, and does `ts-hello` run there with network access?
4. Auth and tenancy: the environment key, the webhook secret, the unauthenticated control plane (Cloudflare Access), and one environment per workspace key.
5. Cost and start-up time compared with Anthropic's cloud environment.

## Deliverable

`docs/reviews/spike-cf-self-hosted.md`: go or no-go, evidence, a proposed task list, and steps for Dom. The prototype runs under `wrangler dev` with a cloudflared quick tunnel for the webhook. No deploys.
