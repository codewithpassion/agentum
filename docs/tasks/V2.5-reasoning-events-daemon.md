Machine runs drop Claude Code's `thinking` blocks (`assistantBlockEvents` in `apps/daemon/src/normalize.ts`). This task records them. If V1 already records reasoning for machine runs, close this task at planning.

## Scope
- `apps/daemon/src/normalize.ts` `assistantBlockEvents`: a non-empty `thinking` block becomes `{ type: "message.reasoning", payload: { text } }`. `redacted_thinking` becomes nothing.
- Keep block order within the message.
- No server change: the event goes up through the existing run events route, which accepts any type in `EVENT_TYPES`.

## Check
- `apps/daemon/src/normalize.test.ts`: thinking, text and tool_use blocks give three events in order; an empty thinking block and a redacted one give none.
- `bun run check && bun run test && bun run build` pass.
