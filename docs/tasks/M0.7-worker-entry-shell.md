From `docs/architecture/build-plan.html#m0`. M0.0 already proved the DO ping; this task keeps it working. Reuse: Ariadne's `cloudflare:workers` shim, The Brain's boundary lint, paths in `docs/architecture/reuse.html`.

## Scope

`server.ts` exports `{ fetch, scheduled }` and the `MachineRelay` class. `wrangler.jsonc` gains cron `* * * * *` at the top level only, R2 `FILES` in all three places, and var `PUBLIC_BASE_URL`. Run `cf-typegen`. `apps/web/src/server/compose.ts` builds every service once per request from bindings and secrets.

Pre-split wiring so the lanes never edit the same file:

- one Hono sub-app per lane under `server/routes/{runtime,access,automation}.ts`, mounted from `server.ts`;
- one tRPC router per lane, merged in `router.ts`;
- a tick registry: `scheduled()` runs every registered job, each lane registers from its own file, and the sweep and the reaper register here;
- gateways registered by injection in `compose.ts`.

`csrf()` applies to every cookie-authenticated non-GET route group; bearer route groups ignore cookies. UI shell: a sidebar with a nav registry each lane appends to from its own file, and an agent page with one tab file per lane (`tabs/chat.tsx`, `tabs/connectors.tsx`, `tabs/slack.tsx`, `tabs/triggers.tsx`, empty until their milestone).

`apps/web/bunfig.toml` with Ariadne's `cloudflare:workers` shim, and the `apps/web` test script changed to `bun test`. The boundary lint from The Brain with the three repo rules.

- The atomic probe: a dev route runs a two-statement `atomic` whose second statement fails, and the first row is absent afterwards on the local D1.
