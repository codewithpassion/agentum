The chat is rebuilt on assistant-ui (MIT) as the task's thread. It ports trueforge's containers as patterns onto shadcn, TanStack Router and tRPC. The trueforge-ui containers are MIT. Code adapted from `assistant-ui-runtime` is Apache-2.0: those files carry a "Modified from trueforge assistant-ui-runtime (Apache-2.0)" header, and the folder ships the Apache 2.0 licence text.

## Scope
- Add `@assistant-ui/react` at a fixed version to `apps/web`.
- New `apps/web/src/components/thread/`: a runtime hook on assistant-ui's external store runtime. It feeds messages from `foldThread` and `applyFrame` (`@repo/protocol/thread`) over V1's session stream. `onNew` calls `runs.start` in the same session.
- Containers adapted from `trueforge/packages/trueforge-ui/src/containers/`: `ThreadContainer`, `ComposerContainer` (attachments through the existing `chat/upload-file.ts` and library picker), `AssistantMessageContainer`, `UserMessageContainer`, `ToolCallContainer` with `ToolGroupContainer` (typed cards, grouped repeated calls), `ReasoningContainer` (collapsed by default), and approval and ask-user parts rendered with V1's cards.
- Edit: "Edit and resend" on the latest user message cancels the run if it is active and starts a new run in the session with the edited text. The old turn stays, marked edited. Say in the UI that the agent still remembers the earlier message.
- Markdown through `components/markdown/markdown.tsx`. Keep the send shortcut from `components/composer/send-shortcut.ts`.
- Mount it in the task view's Thread slot. After a send, navigate to the new run's task view.

## Check

- Browser (dispatcher): a cloud or fake run streams text into the thread, tool calls show as cards grouped ×n, reasoning collapses, an attachment uploads and reaches the run, and edit and resend starts a new run.
- `bun run check && bun run test && bun run build` pass, and grep `apps/web/dist/client` for `drizzle` finds nothing.
