This connects the V6.5 tools to the relay and to Browser Run, so every runtime that uses the platform MCP server gets them.

## Scope
- `apps/web/src/server/mcp/computer-ports.ts` implements `ComputerPort` over the relay port for the agent's `computer_machine_id`, writing `computer.exec` and `computer.file` events. `browser-ports.ts` implements `BrowserPort` over the browser service.
- `apps/web/src/server/browser-run.ts` is the only file that imports `@cloudflare/playwright`, ported from agentum `modules/browser/session.ts` with `persistent: true` and the launch/connect-by-session-id reuse. It implements the `BrowserDriver` port.
- `wrangler.jsonc`: the `BROWSER` binding at top level, in `env.staging` and in `env.staging.previews`. Run `wrangler types`.
- `compose.ts`: build the browser service and pass both ports to the MCP server.

## Check
- `apps/web/src/server/mcp/computer-ports.test.ts` and `browser-ports.test.ts` with a fake relay and a fake driver: offline computer, no computer attached, events written.
- `bun run check && bun run test && bun run build` pass, and grep `apps/web/dist/client` for `playwright` and `drizzle` finds nothing.
- Controller, on staging: an agent's `browser_navigate` and `browser_snapshot` work on a public page.
