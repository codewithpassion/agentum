Asked for by Dom on 19 Oct 2026. The agent's Slack tab (`apps/web/src/components/agent/tabs/slack.tsx`) offers the manifest only as a download, and the Slack app name is always the agent's name: `manifest` in `packages/services/src/slack-apps.ts:174-181` calls `manifestJson` with `name: agent.name`.

## Scope

- On the Slack tab, before the manifest, a "Slack app name" field, prefilled with the agent's name. The manifest uses it for `display_information.name` and, through the existing slug rule in `packages/services/src/slack/manifest.ts`, the bot's display name. Keep Slack's 35-character limit (`DISPLAY_NAME_LIMIT`) in the field, and show it.
- The `manifest` service method and its tRPC procedure take an optional `name`, validated in the service (trimmed, 1 to 35 characters). Without it, the agent's name is used as now. Don't store it: it only shapes the manifest.
- A "Copy" button next to "Download" that puts the manifest JSON on the clipboard and confirms with a short toast or label change. Keep the download.

## Check

- Service test: a custom name lands in `display_information.name` and the bot display name; an empty or 36-character name is refused; no name keeps the agent's name.
- Browser, with dev login on a local dev server: change the name, copy the manifest, and the clipboard holds JSON with the new name; download still works.
- `bun run check && bun run test && bun run build` pass.
