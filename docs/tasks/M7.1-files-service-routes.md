From `docs/architecture/build-plan.html#m7`. Runtime lane, after M1.5. M1.6 (daemon files) depends on this task. Reuse: flightdex-v2 files routes (copy). Paths are in `docs/architecture/reuse.html`.

## Scope

`createFilesService({ db, blobs })`, `POST /api/files` (multipart; a user principal behind `csrf()`, or a run principal, which stamps `run_id`), `GET /files/:id` (a user of the workspace, or a run principal whose run lists the id in `input_file_ids` or `output_file_ids`; 404 on any refusal), R2 key per workspace, 50 MB cap.

Composer upload button; `startRun` attaches the ids; file chips on messages.

## Check

`files.test.ts` with a fake R2:

- a run token can download its input files and upload with its own run id, and gets 404 for any other file;
- a user of workspace A gets 404 for B's file;
- a composer upload by user U cannot be attached to a run started by user V;
- a cross-site form POST without the CSRF header is refused.
