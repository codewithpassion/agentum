This fills the task view's live-computer slot and the take-over card in Needs you. It is ported from agentum `components/workspace/desktop-screen.tsx` onto shadcn.

## Scope
- `apps/web/src/components/computer/desktop-screen.tsx` opens the `/desktop/stream` WebSocket, draws JPEG frames on a canvas, sends acks, shows problems ("Computer offline", "Desktop unavailable") and reconnects with backoff.
- Take over: while holding the lease, mouse and keyboard become `input` messages scaled to 1280x800, with clipboard paste and copy. "I'm done" opens an optional note and calls hand-back. Cancel is available on a pending request.
- The task view's live-computer slot (V2) renders it when the run's agent has a computer, with an anchor for the Slack link (V6.8).
- The Needs you take-over card (V2 desk) shows the reason and an "Open screen" button.

## Check
- Unit tests for the frame and ack handling and the coordinate scaling. Dispatcher browser check against a local desktop image (V6.3) or a fake relay: frames show, take over sends input, and I'm done resumes the waiting run.
- `bun run check && bun run test && bun run build` pass.
