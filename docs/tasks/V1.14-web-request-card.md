The minimum web surface for V1: answer a request on the chat page and set which tools need asking. The desk lane "Needs you" and the agent profile toggles replace both in V2 and V3.

## Scope
- `apps/web/src/components/agent/chat/request-card.tsx`: shown in the transcript at the request's place while it is pending, driven by `request` frames from the stream (V1.6) plus `getTrpc().requests.pending({ sessionId })` on load. Approval: the summary, the scrubbed input in a collapsed block, the expiry as "expires in 42 min", buttons Allow once, Always allow, Deny (Deny takes an optional note). Question: each question with its choices as buttons or checkboxes, and a text field for a free answer. After any surface answers, the card turns into one line ("Allowed once by Dom in Slack", "Expired, nobody answered"). A `conflict` from the mutation shows the line instead of an error.
- Build from existing shadcn components only (`components/ui/`, never edited); logic in `request-card-logic.ts`.
- A short "Ask me before it…" section on the agent's settings tab (`apps/web/src/components/agent/tabs/settings.tsx`): the agent's ask rules as a list with remove buttons, and an input to add a tool key with suggestions for the common ones (`bash`, `write`, `edit`, `web_fetch`, and `<connector>/<tool>` for its connectors). Uses `requests.rules.*`.

## Check
- `request-card-logic.test.ts`: expiry text, settled line per outcome and surface, the answer payload built from choices plus free text.
- `bun run check && bun run test && bun run build` pass, and `apps/web/dist/client` has no `drizzle`.
- Browser check (dispatcher, local dev with the faux model prompts from V1.10 or the fake runtime): an approval card appears, Allow once settles it, a question card with choices sends the chosen answer, an added rule shows in the list and can be removed.
