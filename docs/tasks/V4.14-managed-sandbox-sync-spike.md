Machines and VMs get a live library folder. Managed agents might get one too if their sandbox can run a small sync helper. Otherwise the V4.13 MCP tools are the whole answer.

## Scope
- Try it on staging with one managed agent: can the sandbox run a Bun-compiled helper built from `packages/library-sync` (or a plain script) that pulls the agent's scope with the run token over HTTPS, keeps running during the session, and pushes changes? Check outbound network, process lifetime, disk persistence across turns, and how a session picks up new tools (sessions keep their tool setup).
- Write `docs/decisions/managed-library-sync.md`: what worked, what did not, and the decision.
- If yes: the controller adds a follow-up task to ship the helper. If no: confirm that the V4.13 tool list covers reading, writing and the task folder for managed agents, and name any gap as a new task.

## Check
