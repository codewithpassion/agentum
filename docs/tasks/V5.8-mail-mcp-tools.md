The agent's mail tools, available to every runtime through the platform MCP.

## Scope
- New `packages/mcp/src/tools/mail.ts`: `mail_list` (threads of the calling agent's mailbox), `mail_read` (one thread), `mail_send`, `mail_reply`, using the V5.1 port signatures and input schemas.
- A held send returns a clear "waiting for approval, you will be told the outcome" text, not an error.
- Register the tools only for run principals of agents with an active mailbox.

## Check
- `packages/mcp/src/tools/mail.test.ts` with fake ports: list and read, send sent, send held, reply to a thread, refused for a principal without a mailbox.
- `bun run check && bun run test && bun run build` pass.
