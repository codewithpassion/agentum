The adapter that reads a skill folder from GitHub at an exact commit. It is pure apart from an injected `fetch`, so it is tested with fixtures.

## Scope
- `apps/web/src/server/github-skill-source.ts`: `parseSource` ports the URL, path and ref rules from trueforge `src/schemas/skill.ts`, with an MIT notice and GitHub only. `resolveCommit(repo, ref)` calls the GitHub commits API. `fetchTree(repo, sha, path)` downloads the tarball for that sha, ungzips it with `DecompressionStream`, reads the tar entries (a small reader, no Node APIs) and keeps only `path/`.
- Limits match the skill store (file count, file size, total size), and the result must have `SKILL.md`. It refuses symlinks and `..`.
- Rate-limit and 404 responses become typed failures with readable messages. An optional GitHub token from workspace secrets is passed through for private repos.
- It implements the `FetchedSkillTree` port type from V7.1.

## Check
- `apps/web/src/server/github-skill-source.test.ts` with a fake `fetch` and a fixture tarball: URL and ref validation, sha resolution, subdirectory extraction, size caps, a missing `SKILL.md`, symlink refusal, and 404 and rate-limit messages.
- `bun run check && bun run test && bun run build` pass.

## Refinements (2026-10-27)

Checked against main at 24c28ad. Where these differ from the scope above, they win.

- depends_on stays V7.1.
- `parseSource` uses `githubSkillSourceSchema` from `packages/protocol/src/skills.ts` (V7.1), which already holds the ported trueforge rules, GitHub only.
- `resolveCommit`: `GET https://api.github.com/repos/{owner}/{repo}/commits/{ref}` with `Accept: application/vnd.github.sha`. Every GitHub request needs a `User-Agent` header, or GitHub refuses it.
- `fetchTree`: `https://codeload.github.com/{owner}/{repo}/tar.gz/{sha}`. The API's `/tarball/{sha}` only redirects there and spends an API call. Stream it through `DecompressionStream` and the tar reader, skip entries outside `<top>/<path>/` without buffering them (the top folder is `<owner>-<repo>-<sha7>/`), and stop with a readable failure past 50 MB downloaded (plan default).
- Limits are `SKILLS_MAX_FILES` and `SKILLS_MAX_BYTES` from `@repo/protocol/skills`. The store checks paths again with `assertSafePath` and `assertTreeShape` (`skills-store/paths.ts`).
- Token, plan default: the fetcher takes an optional `token` argument. It does not come from workspace secrets: `secrets.ts` resolves values only for an agent (`resolveForAgent`), and a person importing has no agent. V7.12 passes the optional `GITHUB_TOKEN` Worker secret. Private repos are out of scope for V7.
- Same-file overlaps: none. It is a new file in `apps/web/src/server/`.
