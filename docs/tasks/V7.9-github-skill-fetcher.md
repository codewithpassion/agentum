The adapter that reads a skill folder from GitHub at an exact commit. It is pure apart from an injected `fetch`, so it is tested with fixtures.

## Scope
- `apps/web/src/server/github-skill-source.ts`: `parseSource` ports the URL, path and ref rules from trueforge `src/schemas/skill.ts`, with an MIT notice and GitHub only. `resolveCommit(repo, ref)` calls the GitHub commits API. `fetchTree(repo, sha, path)` downloads the tarball for that sha, ungzips it with `DecompressionStream`, reads the tar entries (a small reader, no Node APIs) and keeps only `path/`.
- Limits match the skill store (file count, file size, total size), and the result must have `SKILL.md`. It refuses symlinks and `..`.
- Rate-limit and 404 responses become typed failures with readable messages. An optional GitHub token from workspace secrets is passed through for private repos.
- It implements the `FetchedSkillTree` port type from V7.1.

## Check
- `apps/web/src/server/github-skill-source.test.ts` with a fake `fetch` and a fixture tarball: URL and ref validation, sha resolution, subdirectory extraction, size caps, a missing `SKILL.md`, symlink refusal, and 404 and rate-limit messages.
- `bun run check && bun run test && bun run build` pass.
