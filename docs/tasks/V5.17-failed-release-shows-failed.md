Found by V5.12 on staging (docs/reviews/tasks/V5.12.md): when the release after Allow once fails (for example Cloudflare refusing the send), the task and desk still say "Allowed once", and the error text is not stored anywhere.

## Scope

- When releasing a held message fails, keep the message `failed` (V5.5 already does) and store the error text on it.
- The approval's settled line on the task and the desk shows that sending failed, with the error, instead of "Allowed once".
- The Mail sheet's Retry stays available for it.

## Check

- A services test: a release that throws leaves the message `failed` with its error, and the request's settled view says the send failed.
- `bun run check && bun run test && bun run build` pass.
