Fills the Files panel slot of the task view with the task folder, replacing output-file chips from `[ATTACHMENT:]` markers.

## Scope
- The Files panel lists the task folder (`agents/<agent>/tasks/<id>/`) from `taskFiles`, live on `library.write` events, with Open in library and Download.
- Below it: files the task edited outside the folder (path, version, mode) and conflicts with a Compare link.
- Old runs with `outputFileIds` keep their chips in the transcript.

## Check
- Browser check (dispatcher, local dev): an isolate run writes a file to its task folder and it appears in the panel while the run is going.
