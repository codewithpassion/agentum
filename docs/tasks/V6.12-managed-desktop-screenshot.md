Managed Agents ignore MCP image results, so a picture of the desktop has to come back through a custom tool result (agentum `anthropic/gateway.ts`). HM's managed event parser already reads `agent.custom_tool_use`.

## Scope
- `packages/services/src/managed/gateway.ts`: declare the `desktop_screenshot` custom tool when the agent's computer reports a desktop, and send `user.custom_tool_result` with a base64 image block.
- `packages/services/src/managed/service.ts`: on a `customToolCalls` entry named `desktop_screenshot`, call an injected `desktopScreenshot(machineId)` dependency and answer the call. An offline or busy computer becomes a text result.
- Attaching or detaching a computer changes the tool set, and a running session keeps its tools, so retire the agent's managed session on the next run after a change.
- The system prompt gains `computerInstructions` from V6.5 when a computer is attached.

## Check
- `packages/services/src/managed/managed.test.ts`: the tool is declared only with a desktop, a screenshot call is answered with an image block, the offline path, and the session is retired after attach.
- `bun run check && bun run test && bun run build` pass.
