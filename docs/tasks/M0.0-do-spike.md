Split out of M0.7 because `docs/HANDOVER.md` asks for it first. Nobody has run a Durable Object under the Cloudflare Vite plugin with TanStack Start in this repo, and every machine milestone depends on it. If it fails, the relay design changes before any contract freezes, so report the failure to the controller instead of working around it.

## Scope

`server.ts` exports the `MachineRelay` class, a placeholder that answers a ping. `wrangler.jsonc` gains the DO binding in all three places (top level, `env.staging`, `env.staging.previews`) and the DO `migrations` block at the top level only. Run `cf-typegen`. A route `/api/machines/ping-do` forwards to the DO.

## Check

`bun run dev`, then `curl localhost:3000/api/machines/ping-do` returns `{ "pong": true }` from inside the DO.
