From M2 gate round 1 (docs/reviews/M2-1.md, finding 1, raised from nit by the controller). `get_run` returns `resultText` to any user in the workspace who has the run id, including runs in another user's private `origin: "ui"` session. `sessions.visibleTo` hides those sessions, but `getRun` does not apply the same rule.

## Scope

In `packages/services/src/runs.ts` `getRun` (around 799-818), apply the same visibility rule that `sessions.visibleTo` applies (`packages/services/src/sessions.ts` around 148-157), by reusing it rather than copying it. A run the caller can't see answers the same not-found as an unknown id. Machine and agent principals keep their current access.

## Check

A service test: user A's run in A's private `ui` session is not found for user B in the same workspace, and is still found for A. A run in a shared session is found for both. The MCP `get_run` tool test covers the B case. `bun run check && bun run test && bun run build` pass.
