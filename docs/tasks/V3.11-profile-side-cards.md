The profile's right column: where the agent runs in plain words, which actions wait for a person, and its latest tasks. It replaces the old Settings tab.

## Scope
- New `components/agent/profile/runs-on-card.tsx`: the three runtimes in plain words ("Anthropic cloud: Managed Agents. Simplest. Has its own sandbox." / "Cloudflare: always on, lowest cost for many small jobs." / "Our machine: <name>: Claude Code on that machine. Sees local files."), with the current one marked. "Advanced" opens the model, machine, environment, network and turn-limit fields from `tabs/settings.tsx` and `agent-form.tsx` in a sheet. Today's update schema can't change the runtime, so other runtimes show as information only.
- `ask-before-card.tsx`: one switch per action from `agentProfile.askBefore`, saving through `setAskBefore`, with a note that outside-contact email arrives with V5.
- `recent-tasks-card.tsx`: the 5 latest tasks with band and time, linking to `/tasks/$runId`, plus "All tasks" (desk filtered to the agent).
- A "Computer" card placeholder that says it comes with V6.
- Delete `tabs/settings.tsx` once its fields live in the sheet, and the `tabs/` folder when empty.
