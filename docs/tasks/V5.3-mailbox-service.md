Each agent gets one address, provisioned on Cloudflare Email Routing, with a state the profile can show.

## Scope
- New portable module `packages/services/src/mail/` (barrel `index.ts`): `createMailService({ db, atomic, clock, events, mailbox: MailboxPort, routing: EmailRoutingPort, domain })`.
- `provision(principal, agentId)`: builds the address from the agent's V3 `email_local` and the domain, checks it is free across the deployment, creates the mailbox in the backend and the routing rule, and moves `provisioning` to `active` or `failed` with the error. Idempotent on retry. `disable` removes the rule and keeps history.
- New agents get a mailbox through the agent-created path of `packages/services/src/agents.ts` (a call, not a schema change).
- tRPC `apps/web/src/server/trpc/mail-router.ts`: `mailbox.get(agentId)`, `mailbox.provision`, `mailbox.disable`.

## Check
- `packages/services/src/mail/mailboxes.test.ts` with fake ports: an address taken in another workspace is refused with the V3 conflict error, a routing failure leaves `failed` with the reason and a retry succeeds, disable removes the rule, people only.
- `bun run check && bun run test && bun run build` pass.
