The builder's LLM output must never name a tool, skill or agent that doesn't exist, and anything it can't settle must show as a yellow gap chip. This pure module defines the draft, checks it against the workspace's catalogue and lists the gaps, so V3.6 only adds the model call.

## Scope
- New portable folder `packages/services/src/agent-builder/` with no drizzle and browser-safe, exported as `@repo/services/agent-builder/draft` and `@repo/services/agent-builder/templates`.
- `agentDraftSchema` (zod): name, does, voice, rules, tools (connector ids), skills (skill ids), startsOn (`{ kind: "routine", cron, label }` or `{ kind: "mail" }` or `{ kind: "slack_mention" }`), handsTo (agent ids), runsOn (`cloud | managed | machine | null`, plus machine id), library paths, and a sample input (key chips) for the dry run.
- `BuilderCatalog` type: connectors (id, name, description, tool names, read-only flags), skills (id, name, description), agents (id, name, does), machines (id, name, online), runtimes available (provider keys present).
- `reconcileDraft(raw, catalog, locked)`: drops unknown ids and turns each into a gap ("No connector for Xero yet. Add one or remove it"). Keeps fields the person edited (`locked`) unchanged. Turns an unset `runsOn` into the gap "Where it runs". Checks the cron with `@repo/services/routines/cron`. Returns `{ draft, gaps: ProfileGap[], didList }`, where `didList` is the "What the builder did" lines.
- `templates.ts`: Sort an inbox, Chase late invoices and Research a topic, each a starter description plus a voice preset. "Import from a file" is UI only (V3.12).

## Check
- `agent-builder/*.test.ts`: unknown connector and skill become gaps; locked fields survive a redraft; a missing runtime is a gap; a bad cron is a gap; an offline machine is noted; each template parses; `didList` matches the draft.
- `bun run check && bun run test && bun run build` pass.
