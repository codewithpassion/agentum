## Scope

- Reproduce it locally with dev login, or on staging with `agent-login --env staging`. Find which call fails and why (a request aborted by navigation or the pending-session gate's reload, a poll started before auth, a real failing route).

- Keep the change small. Anything over about 50 lines becomes a note in the review file instead.
