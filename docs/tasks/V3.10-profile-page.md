The agent page becomes one profile, following `hm-unified/project/Agent.dc.html`, with no org chart and no staff framing. The eight technical tabs go. Their editing UIs live on as sheets opened from the chip rows, so nothing they could do is lost.

## Scope
- `apps/web/src/routes/_app/agents.$agentId.tsx`: the loader calls `agentProfile.profile`. Header: tile, name, address (or "reserve an address"), runtime in plain words, and status ("Paused on task #…" links to the waiting task). Buttons: Edit and Run now (the V2 New task dialog). Drop the `tab` search param and `agent-tabs.ts`.
- New `apps/web/src/components/agent/profile/`: rows Does, Voice (an editable text field saved through `agents.update`), Tools, Skills, Hands to (with Receives from), Starts on, Channels and Library, each as chips with a "+" or Manage action.
- Manage sheets reuse today's panels: Tools opens `tabs/connectors.tsx` and `tabs/secrets.tsx`, Skills opens `tabs/skills.tsx`, Starts on opens `tabs/triggers.tsx` plus routines, Channels opens `tabs/slack.tsx`, Hands to is an agent picker. Move the panels out of `tabs/` into `profile/sheets/` and delete `tabs/sessions.tsx`, since Recent tasks replaces it.
- Library row: home folder plus `libraryPaths`, each labelled read and write, with an edit list. The read-only setting and its enforcement are V4's, so say "Access per folder comes later".
- Leave the side-card column empty for V3.11.

## Check

- Browser (dispatcher): every row renders for a seeded agent; editing the voice saves and shows after reload; each Manage sheet opens and its old actions work (assign a connector, grant a secret, assign a skill, create a trigger, Slack setup).
