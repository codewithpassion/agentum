Managed agents have no file access except the platform MCP, and the `bash` tool handles text only. These tools give every runtime the files, versions and wiki actions, and are the fallback if the V4.14 spike says no sync helper.

## Scope
- `packages/mcp/src/tools/library.ts`: `library_list`, `library_read` (text, or base64 for binary), `library_write` (text or base64, optional `ifEtag`), `library_versions`, beside `bash`. Descriptions name the task folder.
- New `packages/mcp/src/tools/wiki.ts`: `wiki_read` (body, resolved links, backlinks) and `wiki_suggest_edit`.
- `packages/mcp/src/ports.ts`: the ports these tools call. V4.21 wires the real adapters in `apps/web/src/server/mcp/ports.ts`, because that file is in the worker lane.

## Check
- `packages/mcp/src/tools/library.test.ts` and `wiki.test.ts` with fake ports: binary round trip, etag conflict message, a refused path, suggest returns the suggestion id.
- `bun run check && bun run test && bun run build` pass.
