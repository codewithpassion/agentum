From `docs/architecture/build-plan.html#m0`. Provides contracts C3 and C7. Reuse: Ariadne queue transitions as a pattern, durable-pi send-with-wait. Paths are in `docs/architecture/reuse.html`.

## Scope

`createRunsService({ db, atomic, adapters, gateways, blobs, clock, devFakeRuntime })`. `startRun(principal, input)` derives actor and `on_behalf_of_user_id` from the principal, sets `parent_run_id` and depth for run principals and refuses depth above 3, verifies `input.fileIds` belong to the principal's user and workspace, does session get-or-create on `(agent, origin, externalKey)`, and inserts the run. A duplicate `requestId` is caught as the unique violation and the existing run is read back and returned.

Adapter registry keyed by `agents.runtime`; `FakeRuntime` (echo) registered only when `devFakeRuntime` is true. `ingestRunEvents` and `completeRun` refuse with 409 unless the run is `running`, except `completeRun({ status: "aborted" })` on an `interrupted` run, which records `process_ended_at`. `completeRun` writes `result_text` and `output_file_ids` and calls the reply target's gateway with the trusted context. `waitForRun`, `cancelRun`.

The queued-run sweep job re-offers runs queued or offered for more than 60 s through the agent's adapter and downloads leftover `pending_files`. Lease reaper: an expired lease makes the run `interrupted` with a `run.interrupted` event, never re-queued.

`Gateway` interface with a `none` implementation. `agents` service with CRUD, slug rules, `runtime` including `fake`, and its tRPC router. `bun scripts/dev/seed-fake-agent.ts` prints a fake-runtime agent id.

## Check

`runs.test.ts`:

- start a run on a fake-runtime agent, `waitForRun` returns done with the echo, the transcript has `message.user` and `message.assistant`;
- the same `requestId` twice returns the same run id and the second call did not insert;
- a second message on the same session key reuses the session;
- a run started with a run-token principal inherits the parent's `on_behalf_of_user_id`, gets `parent_run_id` set, and a fourth level is refused;
- a trigger-started run has a null subject;
- a fileId owned by another user is refused;
- an event or completion for an `interrupted` run gets 409 and writes nothing, while `aborted` is accepted and sets `process_ended_at`;
- the reaper interrupts a run whose lease passed and leaves it there;
- the sweep re-offers a run that has been queued for 61 s and ignores one queued for 30 s.

`bun scripts/dev/seed-fake-agent.ts` prints an id that `runs.start` accepts.
